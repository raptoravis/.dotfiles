# agent-desktop

Use the installed `agent-desktop` CLI to see and operate desktop applications.
Before the first use, run these commands and follow the returned guides:

```text
agent-desktop skills get desktop
agent-desktop skills get platform
```

These guides match the installed CLI version and include its reference-loading
commands. Run `agent-desktop status` to check platform support and permissions,
and `agent-desktop <command> --help` for command syntax.
